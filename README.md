## Featured project

**[stormshield-toolkit](https://github.com/willcor7/stormshield-toolkit)**: Python tools for Stormshield SNS firewalls.

- Converts CSV rule sets into SNS CLI commands and holds back rules whose objects or interfaces are missing
- Reviews a policy for shadowed, duplicate and conflicting rules
- Groups firewall logs into unique flows to help write the right rule
- Extracts IPsec VPN configuration for import into Stormshield Management Center
